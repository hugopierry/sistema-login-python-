# 🔐 Sistema de Login — Python

Projeto desenvolvido em **Python** com o objetivo de praticar e aplicar conceitos de **Programação Orientada a Objetos (POO)** na construção de um sistema simples de cadastro e autenticação de usuários.

## 📌 Sobre o projeto

O sistema permite criar um usuário e uma senha, confirmar a senha cadastrada e realizar o login utilizando os dados registrados durante a execução do programa.

Este projeto faz parte da minha jornada de aprendizado em **Python e POO** e será aprimorado gradualmente com novos conceitos e funcionalidades.

## ⚙️ Funcionalidades atuais

* 👤 Cadastro de usuário
* 🔐 Criação de senha
* 🔎 Confirmação da senha
* 🔄 Repetição do cadastro caso as senhas sejam diferentes
* 🔑 Sistema de login
* ✅ Validação de usuário e senha
* ⛔ Bloqueio de acesso quando os dados estão incorretos
* ⏳ Uso de `time.sleep()` para simular etapas de processamento
* 💬 Interface no terminal com mensagens e emojis
* 🔐 Senha oculta durante a digitação (via `pwinput`)
